Creator Listings API

Post and update your Developer Marketplace listings from your own scripts or an AI agent. Same rules as the web form: every new listing is screened and then approved by a human before it goes public.

1. Get a key

Open the Creator dashboard → API keys → Create key. The key (duk_…) is shown once, so copy it somewhere safe. You can revoke it anytime. A new key starts working within about a minute, and a revoked key stops within about a minute.

2. Create a listing

curl -X POST https://digitalundergroundstore.com/api/v1/listings \
  -H "Authorization: Bearer $DU_KEY" -H "Content-Type: application/json" \
  -d '{
    "name": "My App",
    "projectUrl": "https://example.com/my-app",
    "category": "apps",
    "pitchShort": "One sentence: what it does and who it is for.",
    "descriptionLong": "A few short paragraphs about features and how to get it.",
    "imageUrl": "https://example.com/cover.png",
    "tags": ["productivity", "mac"],
    "priceLabel": "$9",
    "terms": true
  }'

Response 201 with listing.status = pending (or rejected if screening blocks it, with reasons).

3. Check status / update

curl https://digitalundergroundstore.com/api/v1/listings/LISTING_ID -H "Authorization: Bearer $DU_KEY"

curl -X PATCH https://digitalundergroundstore.com/api/v1/listings/LISTING_ID \
  -H "Authorization: Bearer $DU_KEY" -H "Content-Type: application/json" \
  -d '{"pitchShort": "A sharper tagline."}'

Updates are re-screened. An approved listing stays live while a new video waits for review.

Endpoints

MethodPathWhat
GET/api/v1/listingsYour listings
POST/api/v1/listingsSubmit a new listing (review queue)
GET/api/v1/listings/{id}One listing + status
PATCH/api/v1/listings/{id}Change fields

Full spec: /api/v1/openapi.json · For AI agents: /llms.txt

Rules & limits

  • Limits: name 120, tagline 280, description 4000 characters, up to 6 tags. Image: https URL, or a data URL up to about 750 KB.
  • Videos: https YouTube, Vimeo, .mp4 or .webm links. They go live after review. To upload a video file, use the Creator dashboard.
  • Rate limit: 10 writes per hour and 50 per day per key (HTTP 429 + Retry-After). Reads are not counted.
  • Only list real products you own, with accurate claims. Keys can be revoked by you or by the site owner.
