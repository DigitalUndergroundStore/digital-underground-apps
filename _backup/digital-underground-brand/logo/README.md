Official Digital Underground logos (current as of Oct 20, 2026; same files the live site uses in /workspace/du-dash/assets/logo/).
- du-horizontal.svg/.png: full logo with wordmark (default for pitches, headers, ads)
- du-mark.svg/.png: icon mark only (avatars, small spaces)
- du-mark-white.svg/.png: white mark for dark or photo backgrounds
- favicon-*: site icons
Do not use the old purple "DU" gradient square or redraw the logo. Never put the DU logo on Kerzy Labs games.

STATIC PNG EXPORTS (use these for avatars, banners, decks, listings):
- du-mark.png (1024x1024, square app-icon mark on dark rounded tile)
- du-mark-white.png (1024x1024, white mark, transparent)
- du-horizontal.png (1963x352, transparent background, for dark backgrounds)
- du-horizontal-dark.png (1963x352, on solid #05040c)
- du-horizontal-static.svg = non-animated horizontal SVG. du-horizontal.svg is the animated site version, so don't use it as a still.
