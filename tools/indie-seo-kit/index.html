Meta description formula (≤155 chars)

25-point on-page checklist

  1. One H1, contains primary keyword
  2. Title tag unique per page
  3. Meta description unique and written for clicks
  4. URL short, lowercase, hyphenated
  5. Primary keyword in first 100 words
  6. H2s answer real questions people search
  7. Canonical tag set
  8. Images have alt text and are compressed (WebP)
  9. Page loads in under 2.5s (LCP)
  10. Mobile layout passes, no horizontal scroll
  11. Internal links from 3+ related pages
  12. Links out to 1–2 credible sources
  13. Open Graph + Twitter card image (1200×630)
  14. Structured data (Product / SoftwareApplication / FAQ)
  15. Sitemap.xml includes the page
  16. robots.txt doesn't block it
  17. Submitted / inspected in Search Console
  18. No duplicate thin pages (tag pages, ?params)
  19. HTTPS, no mixed content
  20. 404 page links home
  21. FAQ section with 3–5 genuine questions
  22. Date shown if content is time-sensitive
  23. Clear CTA above the fold
  24. Page answers the query better than result #1
  25. Refresh review every 90 days

Keyword research in 30 minutes

  1. Write 10 problems your users type into Google.
  2. Type each into Google; note autocomplete + "People also ask".
  3. Prefer long-tail ("free invoice template for freelancers canada") over head terms.
  4. Check who ranks: if it's forums/small sites, you can win.
  5. One page per intent. Don't target 5 keywords on one page.

Keyword sheet (CSV columns)

keyword,intent(info/compare/buy),page_url,ranking_now,competitor_1,notes

Page types that work for indie products

  • Free tool / generator pages
  • "[Product] vs [Competitor]" comparison
  • "Best [category] for [audience]"
  • Templates & examples galleries
  • Integration / use-case pages
