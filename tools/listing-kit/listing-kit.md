# Listing Kit
Everything you need to submit a strong listing to Digital Underground (Get listed free → https://digitalundergroundstore.com/list-your-indie-app-free/) or any app/product marketplace.

## 1. Title (max ~50 chars)
Formulas:
- [Name] — [outcome] for [audience]   e.g. "Due Desk — homework deadlines for students"
- [Name]: [category] that [differentiator]
Rules: no ALL CAPS, no emoji spam, name first, outcome over features.

## 2. One-line blurb (max ~140 chars)
"[Name] helps [audience] [do outcome] without [pain]. [Proof or differentiator]."

## 3. Description (3 short paragraphs)
1. The problem in the buyer's words.
2. What it does — 3–5 bullets, benefits first.
3. Who it's for, price, platforms, what's next.

## 4. Screenshot checklist
- [ ] 1200×630 cover for social sharing (text readable at thumbnail size)
- [ ] Hero screenshot shows the core action, not a login screen
- [ ] 3–5 screenshots, each with a 3–6 word caption
- [ ] Real-looking sample data (no lorem ipsum, no personal data)
- [ ] Consistent device frame or none at all
- [ ] Dark/light mode chosen deliberately
- [ ] Compressed (< 300 KB each, JPG/WebP)

## 5. Tags (pick 3–6)
Category (e.g. productivity, finance, AI, education), audience (students, freelancers, creators), platform (web, iOS, Android, desktop), pricing (free, one-time, subscription).
Avoid duplicate synonyms; use words buyers search.

## 6. Links
- [ ] Canonical product URL with UTM (?utm_source=du&utm_medium=listing)
- [ ] Support/contact URL
- [ ] Privacy policy (required if you collect data)

## 7. Final pre-submit check
- [ ] Price stated in currency (e.g. CA$/US$)
- [ ] Links open, checkout works
- [ ] Spelling checked
- [ ] Cover and name match your site
