# Launch Day Kit
A practical checklist and post templates for indie makers shipping a product.

## T-7 days: get ready
- [ ] One-sentence promise written ("X helps Y do Z without W")
- [ ] Landing page: headline, 3 benefits, screenshot, price, one CTA
- [ ] Checkout tested end-to-end with a real card (then refund)
- [ ] Analytics + UTM links set up for each channel
- [ ] Support email or contact form that actually reaches you
- [ ] 3–5 screenshots and a 20–40 s demo clip
- [ ] Social preview (OG) image renders on X, LinkedIn, iMessage
- [ ] List of 20 people who asked for this — message drafts ready
- [ ] Directory list chosen (Product Hunt, Indie Hackers, DU Get listed, niche forums)
- [ ] FAQ: price, refunds, platforms, privacy

## T-1 day
- [ ] Schedule posts; pin nothing yet
- [ ] Prepare a launch-day discount or bonus (optional, with a real end time)
- [ ] Write the "thank you" reply you'll paste 50 times — then personalize it
- [ ] Clear your calendar for the first 6 hours

## Launch day
- [ ] Post on X (thread below), pin it
- [ ] Post on LinkedIn (template below)
- [ ] Send personal DMs/emails to your 20 people
- [ ] Submit to directories
- [ ] Reply to every comment within 1 hour
- [ ] Log every bug/request in one list

## T+1 to T+7
- [ ] Post a results/lessons update (numbers if comfortable)
- [ ] Ship 1 fix from feedback and announce it (see Changelog Kit)
- [ ] Ask happy users for a one-line testimonial
- [ ] Remove expired discount copy

## X launch thread (template)
1/ Today I'm launching [Product] — [one-sentence promise]. 🚀
2/ The problem: [pain in plain words]. I kept hitting it while [your story].
3/ What it does: • [benefit 1] • [benefit 2] • [benefit 3]
4/ [Demo clip / screenshot]
5/ Price: [price]. [Launch bonus, if any, ends DATE].
6/ Try it → [link]. Feedback (even harsh) very welcome. RTs mean a lot 🙏

## Short X post
Shipped: [Product] — [promise]. Built it because [reason]. [link]
