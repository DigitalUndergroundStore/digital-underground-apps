# Testimonial Kit
Turn happy users into social proof — honestly.

## When to ask
- [ ] Right after a win (export done, goal hit, thank-you email)
- [ ] 7 days after purchase
- [ ] When someone praises you publicly — ask to quote it

## Ask templates
- So glad it helped! Mind if I quote that on the site with your name?
- Could you finish this sentence in one line: "Before [product], I ___. Now I ___."
- Would you rate it 1–10? What would make it a 10?

## 5-question feedback survey
1. What were you using before?
2. What almost stopped you from buying?
3. What's the #1 thing it does for you?
4. Who else should use this?
5. What's missing?

## Display
- [ ] Real name + role or handle (with permission)
- [ ] Short quote, bold the outcome
- [ ] 3 quotes near the CTA beats 20 at the bottom
- [ ] Never edit meaning; trim only
