# Price Increase Kit
Raise your prices without losing trust: decide the new price, grandfather fairly, and announce it with ready templates.

## Should you raise?
- [ ] Conversion is healthy (above ~2–3% for digital products)
- [ ] You've added value since the last price
- [ ] Competitors charge more for similar
- [ ] Support/time costs have gone up
Three ticks = raise.

## How much
Test 20–40% steps. Track conversion for 2–4 weeks; if revenue per visitor goes up, keep it.
