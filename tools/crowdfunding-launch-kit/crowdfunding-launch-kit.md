# Crowdfunding Launch Kit
Plan a Kickstarter or Indiegogo campaign for a game, gadget or creative project: goal math, reward tiers, page outline, launch timeline and update templates.

## Goal math
Goal = production cost + shipping + platform fees (~5%) + payment fees (~3–5%) + taxes + 10–15% buffer.
| Line | Cost |
|---|---|
| Production | |
| Shipping & packaging | |
| Platform + payment fees | |
| Rewards / extras | |
| Buffer | |
| **Goal** | |
Set the lowest goal you can actually deliver on; hitting it on day 1 creates momentum.

## Pre-launch (6–8 weeks)
- [ ] Pre-launch page live; collect followers
- [ ] Email list target: enough that 10% conversion = 30% of goal on day 1
- [ ] Press and creator list (see an outreach pack)
- [ ] Video script and shoot (2 minutes max)

## Reward tiers
| Tier | Price | What they get | Limit |
|---|---|---|---|
| Thank you | $1–5 | name in credits | — |
| Digital | | digital copy | — |
| Early bird | | core product at a discount | 100 |
| Core | | core product | — |
| Deluxe | | product + extras | — |
| Premium | | signed / special edition | 25 |
Most backers pick the core tier: make it great value.

## Page outline
1. Video
2. One-line pitch + key image
3. What it is and why it matters
4. Rewards overview graphic
5. Stretch goals
6. Timeline + team
7. Risks & challenges (be honest)
8. FAQ

## Campaign timeline (30 days)
- **Day 1–3:** email list, community, personal network
- **Week 2:** press, creators, update #1
- **Mid-campaign:** stretch goal reveal
- **Last 72 hours:** reminder emails, "ending soon" posts

## Update template
> **Update #[n]: [headline]** We've reached [amount] from [backers] backers. Thank you! What's new: [progress/stretch goal]. How you can help: share [link]. Next: [what's coming].

## After funding
- [ ] Backer survey for sizes/addresses
- [ ] Monthly progress updates until delivery
- [ ] Late pledge store
