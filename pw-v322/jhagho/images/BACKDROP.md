# Motion backdrop asset

`backdrop-food.webp` is a pre-blurred composite (800×900) built from the Pantry Week promo motion backdrop sources on branch `cursor/pantry-week-promo-48eb` (PR #49):

- `promo/pantry-week/bg/r8.webp`
- `promo/pantry-week/bg/r1.webp`
- `promo/pantry-week/bg/r3.webp`

Same recipe photos as the in-app library. Composite + Gaussian blur offline; the app does not apply CSS `filter: blur()` to the photo layer.
