# User Feedback Kit
Ask better questions, get answers you can act on.

## Onboarding survey (after first use, 3 questions)
1. What were you hoping [Product] would help you do?
2. What almost stopped you from signing up?
3. How did you hear about us?

## "Very disappointed" test (product-market fit)
How would you feel if you could no longer use [Product]? Very disappointed / Somewhat disappointed / Not disappointed. — 40%+ "very" is a strong signal.
Follow-up: What is the main benefit you get? Who else would benefit?

## Churn / cancel survey
1. What's the main reason you're leaving? (Too expensive / Missing feature / Hard to use / Switched to [other] / Project ended / Other)
2. What would have made you stay?
3. Can we follow up by email? (y/n)

## 20-minute interview script
1. Tell me about the last time you [did the job your product helps with].
2. What did you use? What was annoying about it?
3. What have you tried to fix that?
4. Walk me through how you use [Product] now. (Share screen.)
5. What would you do if [Product] disappeared tomorrow?
6. If you had a magic wand, what would it do?
Rules: ask about the past, not hypotheticals. Don't pitch. Note exact words.

## NPS follow-ups
- Promoters (9–10): "Thanks! Would you leave a short review / testimonial? [link]"
- Passives (7–8): "What's one thing that would make it a 10?"
- Detractors (0–6): "Sorry it's falling short — what went wrong? I'll reply personally."

## Feedback tagging sheet (CSV columns)
`date,user,source,quote,theme(bug/ux/feature/pricing/praise),severity(1-3),count,status`
Review weekly: sort by count × severity; fix the top 3.

## Testimonial request
> Would you mind if I quoted you? Something like: "[their words, tidied]". Happy to change anything, or skip it entirely.
