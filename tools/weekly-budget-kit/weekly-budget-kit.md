# Weekly Budget Kit
Know where every dollar goes — one week at a time.

## Sunday setup (15 minutes)
- [ ] Write this week's take-home income
- [ ] List bills due this week (see calendar)
- [ ] Set amounts: groceries, gas/transit, fun, savings
- [ ] Income − everything = 0 (give every dollar a job)
