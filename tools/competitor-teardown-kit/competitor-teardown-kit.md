# Competitor Teardown Worksheet
A 90-minute method to understand a competitor and find the gap you can own.

## 1. Pick 3 competitors
- One direct (same job, same buyer)
- One indirect (same job, different approach — often a spreadsheet)
- One aspirational (bigger player your buyers know)

## 2. Teardown grid
| Area | Competitor A | B | C | You |
|---|---|---|---|---|
| Headline promise | | | | |
| Target customer | | | | |
| Pricing (entry / top) | | | | |
| Free tier / trial | | | | |
| Onboarding steps to value | | | | |
| Top 3 features | | | | |
| Integrations | | | | |
| Support channel | | | | |
| Brand tone | | | | |

## 3. Sign up and time it
- [ ] Minutes from landing to first value
- [ ] Number of form fields at signup
- [ ] Emails received in first 7 days (save them)
- [ ] What they ask you to pay for, and when

## 4. Mine the reviews
Read 20 reviews (G2, Capterra, App Store, Reddit). Sort complaints:
| Complaint | Count | Can we fix it? |
|---|---|---|
Look for repeated words — that's your copy.

## 5. Find your wedge
- Underserved segment they ignore:
- Price point they abandoned:
- Workflow they make painful:
- Promise they make but don't keep:
**Our positioning line:** For [segment] who [pain], [Product] is the [category] that [different outcome], unlike [competitor] which [weakness].

## 6. Rules
- Never copy features blindly — copy the job, not the button.
- Re-run every 6 months.
- Be kind publicly; competitors grow the category.
