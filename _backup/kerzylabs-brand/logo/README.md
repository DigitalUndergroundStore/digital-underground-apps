## Usage
- Prefer dark backgrounds (black / near-black). On light backgrounds use the transparent icon; the wordmark is white, so the full logo/lockup needs a dark bg.
- Clear space: at least the height of the "K" stem around the mark. Minimum mark size 16 px (favicon), lockup ≥ 24 px tall.
- Don't recolor, stretch, add outlines, or place on busy imagery.
