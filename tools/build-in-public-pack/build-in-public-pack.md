# Build-in-Public 30-Day Post Pack
One post a day for a month. Fill the brackets, post, repeat.

## 30 daily prompts
1. What I'm building and why it bugs me that it doesn't exist yet.
2. Screenshot of v0. Honest caption: what's ugly about it.
3. The one metric I'm tracking this month and why.
4. A decision I made today and the option I rejected.
5. Something I learned from a user conversation.
6. My tech stack in one image, and one thing I'd swap.
7. Before/after of a UI change.
8. Revenue / users so far (even if zero).
9. A bug that cost me hours — and the fix.
10. What I'm NOT building (and why).
11. Ask: "Which of these two names/designs/pricing pages?"
12. How I find time to build (my weekly schedule).
13. A tool that saved me this week.
14. The first piece of feedback that stung.
15. Week-2 recap: shipped / learned / next.
16. A 20-second demo video.
17. My pricing reasoning in 3 bullets.
18. A competitor I admire and what I learned from them.
19. Something I automated.
20. My launch plan, in public.
21. A user quote (with permission).
22. The worst idea I had this month.
23. Numbers: traffic sources ranked.
24. Thread: 5 mistakes so far.
25. Behind the scenes: my desk / notebook / board.
26. A feature I shipped from a user request — tag them.
27. Ask for help with something specific.
28. Month recap with a chart.
29. What I'd tell myself on day 1.
30. What's next — and a link to follow along / join the list.

## 10 thread skeletons
1. **"I built [X] in [time]. Here's everything:"** idea → stack → hardest part → results → link
2. **"[N] lessons from [milestone]:"** one lesson per post, each with an example
3. **"How I got my first [N] users:"** channel by channel with numbers
4. **"My [$] month, broken down:"** revenue, costs, what moved the needle
5. **"Stop doing [common thing]. Do this instead:"** problem, why, alternative, proof
6. **"The [N]-step process I use to [outcome]:"**
7. **"I asked [N] users why they [churned/bought]. Answers:"**
8. **"Tools I use to run [Product] solo (and what they cost):"**
9. **"[Product] v1 vs v2:"** side-by-side visuals
10. **"What I'd do differently if I started [Product] today:"**

## Hook starters
- "Nobody tells you this about [topic]:"
- "I was wrong about [belief]."
- "Day [N] of building [X] in public."
- "[Number] → [Number] in [time]. Here's what changed."
