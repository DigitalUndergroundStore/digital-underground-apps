# Product Listing Optimizer
A checklist and scorecard to rewrite any digital-product or marketplace listing (Gumroad, Etsy, app stores, your own store) so it converts.

## Title formula
[Outcome] + [Product type] + [For whom]. Example: "Launch-Week Email Sequence — 7 ready emails for indie makers". Keep the key phrase in the first 40 characters.

## Listing scorecard (score 0–2 each)
| Element | 0 | 1 | 2 | Score |
|---|---|---|---|---|
| Title says the outcome | vague | type only | outcome + audience | |
| Cover readable at thumbnail size | no | mostly | yes | |
| First line answers "what do I get?" | no | partly | yes | |
| What's-inside list | none | vague | specific counts | |
| Who it's for / not for | none | one | both | |
| Preview or sample | none | 1 image | real excerpt | |
| Proof (reviews, use cases) | none | 1 | several | |
| Price anchored | no | | compared to time saved | |
| Clear CTA | buried | present | above the fold | |
| FAQ / format / refunds | none | partial | full | |
14+ = strong. Under 10 = rewrite first.

## Description skeleton
1. Hook: the problem in their words
2. What it is in one sentence
3. What's inside (bullets with numbers: "7 emails, 1 tracker")
4. Who it's for / who it's not for
5. Preview link
6. FAQ: format, updates, refunds
7. CTA

## Before/after example
> **Before:** "Email templates for launches."
> **After:** "Launching next month? Get 7 ready-to-edit launch emails, from teaser to last call, with subject lines and a send schedule. Built for solo makers shipping their first product."

## Monthly listing review
- [ ] Check views → sales rate per listing
- [ ] Swap the cover on the lowest-converting listing
- [ ] Add one new review/testimonial
- [ ] Update screenshots if the product changed
